# Чек лист для Sauce Demo

### **1. Авторизация (Login Page)**

* Вход с валидными логином и паролем.
* Вход с невалидным логином и/или паролем.
* Вход с заблокированным аккаунтом.
* Вход без ввода данных (пустые поля).
* Авторизация с пустым паролем.
* Авторизация с пустым логином и паролем.
* Проверка отображения ошибки при неверных данных.

---

### **2. Главная страница (Каталог товаров)**

* Успешный вход на главную страницу (проверка URL и основных элементов).
* Проверка отображения списка товаров после авторизации.
* Сортировка / фильтрация товаров:

  * По возрастанию (A-Z).
  * По убыванию (Z-A).
  * По цене (↑, ↓).
* Проверка корректности отображения цены.
* Просмотр карточки товара.
* Добавление товара в корзину.
* Удаление товара из корзины (из каталога).
* Проверка работы кнопки Remove в каталоге.

---

### **3. Корзина**

* Переход в корзину (проверка URL и элементов).
* Проверка отображения добавленных товаров в корзине.
* Проверка корректности отображения цены.
* Удаление товара из корзины.
* Нажатие кнопки **Continue Shopping** (возврат в каталог).
* Нажатие кнопки **Checkout** (переход к оформлению).

---

### **4. Оформление заказа (Checkout)**

* Ввод валидных данных (имя, фамилия, почтовый индекс).
* Ввод невалидных данных (имя, фамилия, почтовый индекс).
* Попытка отправки пустой формы.
* Проверка итоговой суммы на странице **Checkout: Overview**.
* Проверка стоимости товара и наименования.
* Нажатие кнопки **Finish** (успешное оформление).
* Проверка сообщения **Thank you for your order!**.
* Проверка возврата на главную страницу (в каталог).

---

### **5. Бургер-меню (Navigation)**

* Открытие/закрытие меню.
* Переход в **All Items** (каталог товаров).
* Переход в **About** (страница saucelabs.com).
* Выход из аккаунта (Logout).
* Сброс состояния приложения (**Reset App State**).

---

### **6. Дополнительные проверки**

* Проверка состояния корзины после Logout → Login.
* Проверка адаптивности под разные разрешения экрана.
